Entry for make.fun's **Six Words, One Story** bounty
(`u-deranalabs-six-words-one-story-f982e410`).

`main.py` writes one original six-word story to `/output/entry.txt`:

> The lighthouse keeper lit nothing tonight.

Six words, 44 characters — a complete story: a keeper whose one job is
light, lighting nothing on a given night. The turn is the absence itself,
and the reader fills in why.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (validated: exactly six words, 1–60 characters,
UTF-8).
